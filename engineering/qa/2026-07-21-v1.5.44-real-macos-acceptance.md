# v1.5.44 real macOS acceptance

Date: 2026-07-21

## Scope and safety

Test the exact public arm64 DMG without replacing the pre-existing
`/Applications` copy or using its data. The v1.5.44 instance used a disposable
`/tmp` user-data profile. No update action, social-post, browser-open fallback,
remote publishing queue, or content-generation call was invoked.

## Passed

- Public DMG SHA-256 matched the GitHub Release manifest.
- `hdiutil verify` and DMG stapling validation passed.
- The mounted app passed strict code-signature verification.
- The released app launched from the verified DMG as version `1.5.44` with the
  bundled Python runtime, FFmpeg, and FFprobe reported healthy.
- Video Planner generated a local fallback plan for the disposable topic
  `QA: build repeat clients through consistent follow-up`.
- Selecting **Create from this plan** saved the plan and visibly opened Clips
  with the linked strategy, three Drop Zones, and the plan topic.
- A local scheduler record set far in the future was saved, read back from the
  isolated local queue, and deleted. The queue was empty after cleanup.

## Boundary observed

The direct fixture path failed the app's media validator because it had not been
selected through the native file picker. That is the intended approved-path
boundary, not a media-processing failure. Attempting to drive the native picker
was stopped after the first Apple Events request returned `-1743` (not
authorized). No permission bypass or repeated attempt was made.

## Result

Release install identity, isolated launch, bundled runtime, Plan-to-Clips UI
handoff, and local queue persistence passed. A complete native-picker-to-Scheduler
modal acceptance remains optional follow-up after the automation process is
granted Apple Events access.
