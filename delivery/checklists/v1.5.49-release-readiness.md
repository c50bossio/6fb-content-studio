## Stop conditions

- Stop if the tagged draft is changed, replaced, or its exact manifest no
  longer matches before promotion.
- Stop if a release workflow is already running.
- Stop on any full-suite, runtime, signing, notarization, packaging, updater,
  asset-count, digest, launch, console, network, or browser-sign-in failure.
- Do not delete, skip, or weaken checks to obtain a release pass.

## Boundary

This checklist prepares a reviewable Mac-only release candidate. It does not
create a tag, promote a draft, publish a GitHub Release, post to social media,
or contact customers.
