## Stop conditions

- Stop if the proposed tag target changes after exact-main verification.
- Stop if `v1.5.47` already exists or a release workflow is already running.
- Stop on any full-suite, runtime, signing, notarization, packaging, updater,
  asset-count, digest, launch, console, network, or authenticated-flow failure.
- Do not delete, skip, or weaken checks to obtain a release pass.

## Boundary

This checklist prepares a reviewable Mac-only release candidate. It does not
create a tag, promote a draft, publish a GitHub Release, retire the historical
YouTube key, run a scheduler, post to social media, or contact customers.
