# v1.5.47 macOS release preparation evidence

Date: 2026-07-22

## Scope

This is preparation evidence only. It records a clean local candidate based on
`origin/main` commit `fa959f8f1b2366e216f0ada67762018d45912835`, before the
release-note/checklist handoff commit. It does not create a tag, package a
signed installer, publish a GitHub Release, or prove an authenticated desktop
session.

`v1.5.46` is the current public macOS-only release at annotated tag target
`f81b63b7b9400fb76cd37d399f366b9a3fbb2aed`. Smart Live Trends merged later
through pull request #37, so the next available patch version is `v1.5.47`.

After review found that the original tag workflow would automatically promote a
release before the authenticated Smart Trends flow was checked, the candidate

signed, notarized, stapled private draft. The separate
`publish-release.yml` workflow requires an explicit dispatch, rechecks the
exact four-asset draft, then performs anonymous public-manifest and DMG smokes
after promotion. The corrected candidate passed `npm test`, `git diff --check`,
and Actionlint v1.7.7 across `release.yml`, `publish-release.yml`, and
`release-windows.yml`.

## Release-path checks

- Current `origin/main` and the public v1.5.46 tag have byte-identical release
  workflow files.
- The tag-triggered workflow is macOS-arm64-only. It stages and verifies exactly
  the DMG, updater ZIP, ZIP blockmap, and `latest-mac.yml` before publication.
- The Windows workflow is manual-only and uses `--publish never`; it cannot be
  called by the production tag workflow.
- Required Apple signing/notarization and GitHub release secret names are
  present without reading secret values.
- `v1.5.47` is unused at preparation time.
