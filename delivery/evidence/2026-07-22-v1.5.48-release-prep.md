## Runtime dependency reproducibility

The first clean pre-tag runtime rebuild correctly failed before tag creation:
fresh PyInstaller 6.21 attempted to thin an already arm64-only bootloader, and
after a local PyInstaller-only rollback the freshly resolved SciPy runtime
imports failed in the frozen executable. The release builder previously had no
lock for these Python package inputs.

The corrective candidate adds the tracked macOS-arm64 constraints file,
enforces it in the runtime builder, and adds a static contract. A fresh empty
runtime environment then rebuilt successfully with PyInstaller 6.20.0,
completed the packaged executable and redirected-UTF-8 probes, and passed the
full suite: 62 unit tests, 80 IPC/static contracts, CDP, documentation, Python,
runtime, production build, and isolated Electron IPC smoke. Normal, strict, and
portable workspace validation and Actionlint for the release workflows also
passed. This proof must be repeated on the exact merged tag target.
