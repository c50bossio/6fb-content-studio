# 6FB Content Studio v1.5.44

Status: published 2026-07-21.

## What changed

- Added Guided Plan-to-Post handoffs from Video Planner to Clips, from clips to
  Video Editor or Scheduler, and from editor export to an editable local
  scheduling draft.
- Added local media validation and local-first scheduler queue loading so stale
  paths and disconnected remote queues do not silently route a user elsewhere.
- Preserved explicit scheduling and posting boundaries: the workflow ends at a
  local draft and does not publish content automatically.

## Verification

- Build, workspace validation, renderer smoke, and packaged source-to-local
  schedule acceptance passed before release.
- macOS and Windows tag workflows passed, including the macOS notarization and
  published-DMG smoke and the Windows application launch smoke.
- A fresh public macOS DMG download matched its published SHA-256, passed DMG
  stapling and strict signature checks, and launched from an isolated profile as
  version `1.5.44`.
