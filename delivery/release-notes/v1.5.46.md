# 6FB Content Studio v1.5.46

## Improved

- Strengthens local-media security with canonical path checks, exact-file
  approvals, symlink-retarget protection, narrow app-owned media access, and
  immediate approval revocation after app reset.
- Makes clip trimming transactional and concurrency-safe, verifies the rendered
  video stream and duration, and rolls metadata back when processing fails.
- Makes pipeline, research, composition, export, and publishing failures return
  truthful errors instead of appearing successful after incomplete work.
- Adds bounded timeouts and hard failure caps around supported external calls.
- Improves Scheduler reliability by awaiting publishing handoffs, surfacing
  failures, and preventing duplicate or destructive actions while work is in
  progress.
- Improves keyboard accessibility across navigation and dialogs with focus
  entry, Tab and Shift+Tab containment, Escape handling, inert backgrounds, and
  opener-focus restoration.
- Improves responsive layouts across planning, creation, editing, scheduling,
  analytics, setup, and settings screens at phone, tablet, and desktop widths.
- Strengthens macOS and Windows release workflows with the complete test suite,
  bundled-runtime checks, and explicit native-command failure handling.

## Upgrade notes

- External media saved by an older version may require one native file-picker
  re-selection before it can be previewed or scheduled. No media is deleted.
- The advanced pipeline CLI now fails closed for unsupported direct `--post`
  requests. Optional `--compose` use requires the separate Remotion workspace;
  the shipping Electron workflow continues to use the verified FFmpeg runtime.

## Verification prepared

- Full automated coverage includes path-safety and clip-metadata unit tests, 68
  preload-to-main IPC contracts, CDP fault handling, documentation contracts,
  Python and bundled-runtime checks, a production build, and isolated Electron
  IPC smoke.
- The final responsive matrix contains 47 captures at 375, 768, and 1440 px
  with zero layout, touch-target, console, or network findings and verified
  44 px interaction targets.
- Release workflows run the full suite before packaging and separately validate
  the bundled macOS and Windows runtimes.

## Certification

The coordinated release workflow stages both platform artifact sets, verifies
the notarized macOS DMG from the draft release, and publishes only after those
gates pass. Independent downloaded-installer acceptance is recorded separately
from workflow completion.
