# 6FB Content Studio v1.5.51

## More accurate Instagram ideas

- Fixes the Instagram signal source used by **Trending** for accounts connected
  through Instagram Login.
- Uses only a bounded set of recent, authorized account media for Instagram
  ideas; the app no longer attempts public hashtag discovery with the wrong
  token model.
- Keeps Instagram account signals visible alongside Google Trends and your
  Content Planner topics, rather than allowing a broad Google response to
  crowd them out.
- Labels those ideas accurately as account signals. Instagram is not presented
  as a public, niche-wide hashtag trend source.

## Certification

This release targets **macOS arm64 only**. The tag workflow stages exactly the
DMG, updater ZIP, ZIP blockmap, and `latest-mac.yml` as a private draft and
verifies the notarized DMG before publication. Windows distribution remains
deferred pending measured Mac adoption.
