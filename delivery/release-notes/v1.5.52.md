# 6FB Content Studio v1.5.52

## More reliable Clip Extractor checks

- Prevents the desktop health check from waiting indefinitely while validating
  the bundled Clip Extractor runtime.
- Keeps the fast desktop preflight lightweight, while retaining the full
  bundled-runtime verification during packaging.
- Packages the macOS runtime without the optional audio dependency that can
  block MediaPipe initialization; video reframing remains fully verified.
- Loads Clip Extractor commands only when they are used, so routine command
  paths do not initialize video-processing dependencies unnecessarily.

## Certification

This release targets **macOS arm64 only**. The tag workflow stages exactly the
DMG, updater ZIP, ZIP blockmap, and `latest-mac.yml` as a private draft and
verifies the notarized DMG before publication. Windows distribution remains
deferred pending measured Mac adoption.
